# CADIC HOME DEVELOPPEMENT — Site de démonstration

Site vitrine responsive réalisé avec Next.js 14, TypeScript, Tailwind CSS et Lucide React.

## Lancer le projet

Prérequis : Node.js 18.17 ou supérieur.

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000.

Pour générer une version de production :

```bash
npm run build
npm run start
```

## Sections incluses

- Accueil
- Bandeau de chiffres (95 logements annoncés, 4 programmes en cours — à valider)
- À propos
- Notre mission
- Nos projets : projets réalisés et projets en cours
- Actualités (état vide de démonstration)
- Galerie
- Contact et accès WhatsApp

## À valider avant mise en ligne publique

- Les statuts et noms des projets ainsi que toutes leurs caractéristiques.
- Les coordonnées, l’adresse et les horaires officiels.
- Remplacer les photographies Unsplash par les photos réelles fournies et autorisées par CADIC HOME.
- Remplacer le contenu de démonstration des actualités par des publications approuvées.
- Vérifier le numéro WhatsApp de contact.

Les images actuellement utilisées sont des visuels d’illustration et ne représentent pas nécessairement les projets de CADIC HOME. Le site doit être présenté comme une proposition de démonstration non officielle, en attente de validation par l’entreprise.
